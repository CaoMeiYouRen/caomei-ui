> 一个基于 Vue 3 和 Reka UI 的自建组件库，强调组件与样式解耦，默认提供极简可用的样式并支持 100% 自定义覆盖。开箱即用主题切换与暗色模式，组件设计适配桌面端与移动端。

[https://github.com/CaoMeiYouRen/caomei-ui#readme](https://github.com/CaoMeiYouRen/caomei-ui#readme)


## 📦 依赖要求


- node >=20

## 🚀 安装

```sh
npm install
```

## 🛠️ 开发

```sh
npm run dev
```

## 🔧 编译

```sh
npm run build
```

## 🔍 Lint

```sh
npm run lint
```
