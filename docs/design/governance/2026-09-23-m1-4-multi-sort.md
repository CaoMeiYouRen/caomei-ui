## 1. 范围与目标

为 `CaomeiDataTable` 补**多列排序**与**降序优先**，**API 命名对齐 PrimeVue**（用户裁定 D2）：`sortMode="multiple"` + `v-model:multiSortMeta`（多键 + 方向）；暴露 `sortDescFirst`（用户裁定 D4：首次点击方向可配）。与既有单列排序路径互斥且不回归。

非目标：`removableSort` 开关、`nullSortOrder`、列级 `defaultSortOrder`、筛选 / 分面（本轮不涉及）。

## 2. API 契约（对齐 PrimeVue 的命名映射）

| PrimeVue | 本库 | 说明 |
| :--- | :--- | :--- |
| `sortMode="single" \| "multiple"` | 同名 | 默认 `single`；需在挂载时确定 |
| `v-model:multiSortMeta` | 同名（`DataTableSortMeta[]`） | `{ field: 列 key, order: 1 \| 0 \| -1 }`，按优先级排列；`order: 0` 被忽略 |
| `defaultSortOrder`（表格级 / 列级数值） | `sortDescFirst`（表格级布尔量） | 决定首次点击方向；单列与多列模式均生效 |
| `update:multiSortMeta` | 同名 | 受控回写；两种模式都抛出 |
| 列头点击：`metaKey` 追加 / 无修饰键收敛 | 同语义 | 按住 Cmd / Ctrl 追加为下一个排序键（已在列表中则翻转方向），不按修饰键收敛为该列单列排序 |
| 多列排序优先级徽标 | 表头内优先级序号（`.caomei-data-table__sort-index`） | 仅 `sortMode="multiple"` 且该列参与排序时渲染 |

行为口径：排序键按「升 → 降 → 移除」循环（第三击移除，`sort` 载荷 `sortOrder` 为空字符串）；多列模式下 `sort` 载荷额外带 `multiSortMeta`（完整排序键），`sortField` / `sortOrder` 仍取第一优先级。

## 3. 有意差异（逐条）

1. **`DataTableSortMeta.field` 只接受列 key**（上游允许字段函数），**`order` 只接受 `1 | 0 | -1`**（上游允许 `undefined` / `null`）。
2. **上游 `defaultSortOrder` 有表格级与列级两种形态**，本库只提供表格级 `sortDescFirst`。
3. **上游 `removableSort` 开关本库未提供**：排序键固定按「升 → 降 → 移除」循环（与既有单列路径一致，源于 tanstack `enableSortingRemoval` 默认 `true`）。
4. 多列模式下 `sort` 载荷额外带 `multiSortMeta`（上游 `sort` 走 lazy-load 事件形态）。

## 4. 实现落点

- `src/components/data-table/types.ts`：`DataTableSortMode` / `DataTableSortMeta`、`DataTableSortEvent.multiSortMeta`、props `sortMode` / `multiSortMeta` / `sortDescFirst`（含中文 JSDoc + `@en`）。
- `src/components/data-table/index.ts`：导出 `DataTableSortMeta` / `DataTableSortMode`。
- `src/components/data-table/data-table.vue`：
  - `isMultipleSort`；`sortingState` 双模式派生（`multiple` 由 `multiSortMeta` 过滤 `order !== 0` 后映射为 `{ id, desc: order === -1 }`，`single` 维持既有 `sortField` / `sortOrder`）；
  - `isSortControlled` 分支（`multiple` 看 `multiSortMeta !== undefined`，`single` 看 `sortField !== undefined`）；
  - `toggleSort(key, event?)`：`multiple` 下调 `column.toggleSorting(undefined, Boolean(metaKey) || Boolean(ctrlKey))`，`single` 维持既有调用；
  - 抽出 `emitSortChange(next)` 统一抛出 `sort`（多列额外带 `multiSortMeta`）与 `update:multiSortMeta`；
  - `useTable` 的 `sortDescFirst` 由固定 `false` 改为 `computed(() => props.sortDescFirst)`（缺省仍是 `false`，单列路径零漂移）；
  - 新增 `sortIndex(key)` 与表头优先级序号 span（仅多列模式且该列参与排序时渲染）。
- `src/components/data-table/data-table.sorting-multi.test.ts`（新增，19 条）：单列零漂移（含 `sort` 载荷严格比对、不抛 `update:multiSortMeta`） / `sortDescFirst` 两种取值与「升→降→移除」循环 / 受控 `sortField` 运行期切换 / 无修饰键收敛 / 修饰键（`metaKey` 与 `ctrlKey`）追加与翻转 / 受控回写后继续追加 / 多列三击移除 / 受控 `order: 0` 忽略 / 受控不采纳与回写 / 自持累积 / 受控切自持 / 多键 tie-break 与 `aria-sort` / 与行分组同用。
- 文档：中英组件页「排序」节补「降序优先」与循环说明 + 新增「多列排序」子节 + 迁移映射 3 行 + 范围与约定（浅响应载体） + 无障碍（多列 `aria-sort` 与序号取舍）；中英新示例 `sorting-multiple.vue`；[设计规范 §7](../design-spec.md) 映射与有意差异；并更正 §7 中「内部固定 `sortDescFirst: false`」的旧表述（Review Gate RG-W01）。
