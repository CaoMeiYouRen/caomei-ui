## 3. 计算工具与可复现性

```bash
# 复算脚本：/tmp/compute-contrast.mjs
# 依赖：WCAG 2.1 相对亮度公式 (sRGB -> 线性 -> 加权)
# L = 0.2126*R + 0.7152*G + 0.0722*B
# Contrast = (L_lighter + 0.05) / (L_darker + 0.05)
```

**可复现命令**：
```bash
node /tmp/compute-contrast.mjs
```
