## 4. 替代取证边界（必须显式声明）

M1-1 的验收表述含「registry 校验与**发布日志**一致」。**发布日志在用户本地、仓库内不可得**（本仓不承载发布执行），故本轮以**替代取证**承载，并在此声明其边界：

- **已证**：registry 上的产物与**预期版本**一致——版本号、`shasum` / `integrity`、文件数、体积、包形态、依赖面、解包冒烟全部通过，且与**发布前**本仓 `npm pack --dry-run`（**358** 文件 / 195.0 kB packed / **858.4 kB** unpacked）逐值吻合。**范围不含包内 `README` 的版本表述**（该文件随 0.4.0 打包，页面仍显示 0.4.0，见 §7）。
- **未证**：与真实发布日志**逐条**一致（日志不在本仓）。后续如需该级证据，须在发布执行时同步留存日志（或改用 CI 侧发布以自动留痕）。
