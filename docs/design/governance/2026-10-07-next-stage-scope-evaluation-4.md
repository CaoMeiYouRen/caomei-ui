### 4.1 各主线执行口径

- **M1 测试装置与覆盖扩面**
  - 执行范围：给 Phase 19 遗留的四处「未纳入面」补装置——① Tabs 指示条纳入 `capture:styles` 采样面（重冻结前评估 Tabs 采样是否稳定，动画 / 瞬态属性按既有原则排除），若判定不宜采样则以「常驻 E2E 为唯一承载」显式登记边界；② 焦点可见扩面（把 CDP `CSS.forcePseudoState` 驱动的可见焦点环断言扩到其余含 `:focus-visible` 的组件，按可稳定驱动者分批）；③ 禁用态几何扩面（把「禁用前后尺寸不变」断言扩到更多组件对）；④ 文档站浮层泄漏的常驻浏览器断言（把 M3-2 的一次性探针转为常驻 / CI 断言）。
  - 非目标：不为不可稳定驱动者强行造断言；不改组件行为（`src/**` 零行为变更，除扩面暴露的缺陷另行处置）；不引入外部视觉回归服务。
  - 最小验收：新增 / 修改断言具**负向对照**；`capture:styles` 重冻结后 0 差异；受检面有下界守卫（防静默收窄）；涉及渲染走 `@ui-validator`。
- **M2 基建与治理守卫补口**
  - 执行范围：① a11y 同类悬空引用（DropdownMenuGroup / RadioGroup 的 `aria-labelledby`、Accordion 折叠触发器的 `aria-controls=""`）——先复验再定修法（slot 形态在位检测 / 时序）；② 把文档站主题 CSS（`docs/.vitepress/theme/**`）纳入 stylelint 或独立规则面；③ 浮层交互 E2E 规格（ConfirmDialog / Dialog 焦点落位、滚动锁复位）与既有 E2E 去重；④ 执行层规则重述与失效引用收敛（`code-reviewer` SKILL.md）。
  - 非目标：不为可机检性强行把人工约定升格为断言；不改 a11y 的**有意例外**（Toast 焦点哨兵维持现状）。
  - 最小验收：守卫触发可复现且具负向对照；`governance:check` / `ai:check` 全绿；a11y 改动走 `test:a11y` 与真实浏览器复核。
- **M3 下游协同与 Phase 8 评估**
  - 执行范围：出 **Phase 8 范围评估**（已接入下游清单 + 跨仓库 CI 触发形态 + 容量边界），**评估不等于启动**；下游升级护航仅在下游触发时维护口径。
  - 非目标：不为下游做他仓迁移实施；不修改下游仓库；不建立跨仓 CI 触发实体（除非另行授权启动）。
  - 最小验收：评估给出触发形态与容量边界；口径逐载体 `rg` 复核无旧口径残留。
- **M6 发布收口**
  - 执行范围：把 Phase 19 起积累的 `src/**` 变更（浮层背景 / 阴影 token、Tabs 几何、Drawer reduced-motion）交付为 **0.6.0**——发布前触发[长期任务](../../plan/recurring.md)门槛复核轮、`pnpm verify` 全绿、版本句 / CHANGELOG 同步、发布后校验；可选顺带 B31 CHANGELOG 生成器健壮性收口。
  - 非目标：不重写已发布 tag；不启用 CI 自动发布（沿用本地手动发布）；不做破坏性 API 变更（除非另行裁定）。
  - 最小验收：`release:verify` 通过（registry / tarball shasum / 解包冒烟）；`docs:check:version` exit 0；发布执行治理记录。
- **M4 组件能力与长尾**（可选）
  - 执行范围：仅在下游出现真实用例的前提下，按用量优先级落地 1 ~ 2 项（如 `DatePicker` 范围选择 / `DataTable` 滚动高度）。
  - 非目标：无下游用量的能力扩充不纳入。
  - 最小验收：有下游用例取证 + 新增能力默认关闭时既有行为零漂移（`capture:styles` 0 差异）。
- **M5 国际化路线落地**（可选）
  - 执行范围：按 M7-1 结论择一落地——扩语言（`ru` / `fr` / `de` / `es` / `pt` 按需）或 locale 分包路线 A / B；RTL 单独立项评估。
  - 非目标：不追头部库语言量级；不在未评估时引入 `dir="rtl"` 全局改动。
  - 最小验收：`check:locale-keys` / `check:locale-ledger` 基线同步；分包方案须有产物体积前后实测。
- **M7 视觉回归基线**（可选）
  - 执行范围：评估 Playwright 截图比对的形态（基线库、容差策略、CI 集成成本），产出立项建议。
  - 非目标：评估阶段不建实体基线。
  - 最小验收：给出成本 / 收益与最小可用形态。
