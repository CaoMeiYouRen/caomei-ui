### 4.1 各主线执行口径

- **M1 机制真实贯通**
  - 执行范围：① 以 `workflow_dispatch` 触发 `downstream-compat.yml`（被测版本按需传入），验证 Actions 运行时（表达式求值 / checkout 权限 / 缓存 / 下游复刻构建链）并将结论回传治理记录；受检清单按「接入即登记」维护（dependfix 试点，momei 迁移完成后增量登记）；② 以 `workflow_dispatch` 触发 `regression-weekly.yml`（或在下次定时 run 时）复核视觉基线首个 `ubuntu-latest` run 的跨环境渲染一致性（字体 / 抗锯齿），按需重冻结基线，再评估转阻断；可选按 D7 扩受检面。
  - 非目标：不为下游做他仓迁移实施；不改下游业务代码；检查范围**不含** e2e / 全量单测 / 覆盖率；不建快照库。
  - 最小验收：下游兼容检查有**一次真实 run** 且结论可归因（记录下游 SHA）；视觉基线首个 CI run 结论落到治理记录并给出**转阻断判定**（维持非阻断须写明理由与再评估触发）。
- **M2 依赖安全与升级治理**
  - 执行范围：① 运行时作用域安全告警（`source-map-js` high）**立即插队处置**（锁定修复到 `1.2.2`，方式 = 锁定更新 / `pnpm.overrides`，`pnpm-lock.yaml` 同提交）；② 开发作用域 15 项盘点（含 `node-forge` 无修复版本一项的处置结论）并按可修复性分批；③ 大版本升级（`vite` / `vitest` / `typescript` / `conventional-changelog`）逐项评估与迁移，含 7 个 open PR 的取舍。
  - 非目标：不引入新运行时依赖；不为升级而升级（评估不达标者退回条件触发）；不破坏公共导出面；变更 `src/**` 之外的依赖升级须保证 `pnpm verify` 全绿。
  - 最小验收：运行时告警清零（`gh api .../dependabot/alerts` 复核）；dev 项每条有「复算值 + 修复版本 + 结论」；大版本升级项有迁移记录 + `pnpm verify` exit 0（库产物冒烟）。
- **M6 治理与测试收口**
  - 执行范围：① 归档载体行数处置（B26：压缩近线窗口 / 更早阶段迁深度归档，或维持并留观察+再评估触发）；② 治理 / 测试收口精选（B16 ~ B20、B22 中达门槛者，须先定告警面与误报口径，避免高误报守卫）。
  - 非目标：不改已发布 tag 与点时记录；不引入高误报守卫；不压缩历史快照类记录。
  - 最小验收：载体行数处置有判别口径（`docs:check:line-count` 复跑 + 主窗口时间序不变）；新增守卫有判别力自证（负向对照）。
- **M3 发布机制演进**（可选）
  - 执行范围：按[发布机制评估](./2026-10-08-release-flow-and-version-strategy-evaluation.md)择项落地（提交驱动 CI 自动发布 + OIDC、1.x 策略、CHANGELOG 健壮性）。
  - 非目标：不启用定时自动发布；breaking 直接升 `1.0.0` 须先定拦截策略；不重写已发布 tag。
  - 最小验收：`pnpm verify` 常驻前置 + 凭据最小权限 + breaking 拦截；`release:verify` / `docs:check:version` 通过。
- **M4 组件能力与下游护航**（可选）
  - 执行范围：仅在下游出现真实用例的前提下，按用量优先级落地 1 ~ 2 项；产出 momei `0.3 → 0.5` 升级指引（触发时）。
  - 非目标：无下游用量的能力扩充不纳入。
  - 最小验收：有下游用例取证 + 新增能力默认关闭时既有行为零漂移（`capture:styles` 0 差异）。
- **M5 国际化与 RTL 路线**（可选）
  - 执行范围：按既有调研结论择一落地（扩语言 / locale 分包路线 A 或 B；RTL 单独立项评估）。
  - 非目标：不追头部库语言量级；不在未评估时引入 `dir="rtl"` 全局改动。
  - 最小验收：`check:locale-keys` / `check:locale-ledger` 基线同步；分包方案须有产物体积前后实测。
- **M7 发布收口**（按需）
  - 执行范围：本阶段若产生 `src/**` 行为变更则发新版本；当前 0.6.0 已闭环、**无在途 `src/**` 变更**，故默认**无此条目**。
  - 非目标：不重发 0.6.0；不重写 tag。
  - 最小验收：`release:verify` 通过；`docs:check:version` exit 0；发布执行治理记录。
