### 4.1 各主线执行口径

- **M1 机制收口与回归判别力**
  - 执行范围：① 推送后复核远端 `regression-weekly.yml` 的**首个阻断形态 run**（确认 `continue-on-error` 已移除、失败面可归因、周级无人值守下的告警路径可用）；② 视觉基线**受检面扩面**（B25：补拉丁 / `system-ui` 回退文本路径，按需补日期 / 浮层 / 多视口 / 主题预设），扩面须**同批重冻结基线 + 负向对照**；③ 下游兼容检查的**版本差判别力**（N3：下次发布或以显式版本入参触发使被测版本与下游锁定版本产生差异），补齐 run #1 的未覆盖边界。
  - 非目标：不为下游做他仓迁移实施；不改下游业务代码；检查范围**不含** e2e / 全量单测 / 覆盖率；不建快照库；不因扩面而引入高误报断言。
  - 最小验收：远端阻断生效有**一次真实 run** 记录（含运行器镜像字段与失败面）；扩面后有**冻结基线 + 负向对照命中**（判别力自证）且 `test:visual` 全绿；版本差 run 有**下游 SHA + 版本对**双归因，能区分「管道贯通」与「回归判别力」。
- **M2 依赖与 CI 环境治理**
  - 执行范围：① **Ubuntu 26.04 迁移应对**（B26，**2026-10-19 起**）：按裁定处置 10 处 `runs-on`（钉固定镜像标签 / 维持 `ubuntu-latest`），并按 M1-2 既定检测点（`Set up job` 日志 `Image:`）在迁移落地时**重冻结视觉基线**；② **陈旧 PR 清理**（N1：`vite 8.3.0` / `vitest 4.1.11` 因基线过期可关闭并说明本仓现值）+ 延后项跟踪（B27 / B28 维持条件触发，逐条写明再评估触发）；③ 可选：把依赖告警 / PR 巡检登记为长期任务批次（若用户认可方向）。
  - 非目标：不为升级而升级（不达标者维持条件触发）；不引入新运行时依赖；不因清理 PR 而改动 `package.json` 以外文件（陈旧 PR 的关闭属 GitHub 侧操作，不进代码提交）。
  - 最小验收：迁移应对有明确形态与检测点（钉定则列出全部处数并逐处核对，维持则写明再评估触发）且 CI 全绿；PR 清理逐条给「本仓现值 + PR 基线 + 处置」；延后项维持条件触发并留再评估触发句；`pnpm verify` exit 0。
- **M6 治理与测试收口**
  - 执行范围：① 归档载体行数处置（B22：**574 行 / error 阈值 600**——压缩近线窗口（更早阶段迁深度归档）或压缩单块粒度，或维持并写明再评估触发）；② 文档站示例外链图片守卫（B29：扫描 `docs/**/examples/**` 的图片源，接入 `docs:check`，须带判别力自证）；③ Phase 22 记录完整性（N4：为缺失库内记录的五条补录归并记录，或将该偏差转为可复核形态）。
  - 非目标：不改已发布 tag 与点时记录；不引入高误报守卫；不压缩历史快照类记录（迁移而非删改）；不重写已归档阶段块的事实性内容。
  - 最小验收：行数处置后 `pnpm docs:check:line-count` 复跑（主窗口时间序不变、归档块事实未被改写）；新增守卫有**负向对照**（故意注入外链图片时命中，移除后通过）；补录记录与既有归档块计数口径一致（无第二事实源）。
- **M3 发布机制演进**（可选）
  - 执行范围：按[发布机制评估](./2026-10-08-release-flow-and-version-strategy-evaluation.md)择项落地（提交驱动 CI 自动发布 + npm OIDC、1.x 策略、CHANGELOG 健壮性）。
  - 非目标：不启用定时自动发布；breaking 直接升 `1.0.0` 须先定拦截策略；不重写已发布 tag。
  - 最小验收：`pnpm verify` 常驻前置 + 凭据最小权限 + breaking 拦截；`release:verify` / `docs:check:version` 通过。
- **M4 组件能力与下游护航**（可选）
  - 执行范围：仅在下游出现真实用例的前提下按用量优先级落地 1 ~ 2 项；B31 待用户裁定后按结论结转（重评估 / 关闭）。
  - 非目标：无下游用量的能力扩充不纳入。
  - 最小验收：有下游用例取证 + 新增能力默认关闭时既有行为零漂移（`capture:styles` 0 差异）。
- **M5 国际化与 RTL 路线**（可选）
  - 执行范围：按既有调研结论择一落地（扩语言 / locale 分包路线；RTL 单独立项评估）。
  - 非目标：不追头部库语言量级；不在未评估时引入 `dir="rtl"` 全局改动。
  - 最小验收：`check:locale-keys` / `check:locale-ledger` 基线同步；分包方案须有产物体积前后实测。
- **M7 发布收口**（按需）
  - 执行范围：本阶段若产生 `src/**` 行为变更则发新版本；当前 0.6.0 已闭环、**无在途 `src/**` 变更**，故默认**无此条目**。
  - 非目标：不重发 0.6.0；不重写 tag。
  - 最小验收：`release:verify` 通过；`docs:check:version` exit 0；发布执行治理记录。
