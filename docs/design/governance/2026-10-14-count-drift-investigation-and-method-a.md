- **证据 C（成本）**：M3-1 与 M3-2 **两个条目**因计数类 findings **多耗 3 轮 RG**（M3-1 R2、M3-2 R2、M3-2 R3，均在默认 3 轮预算内）+ **4 个 blocker**（逐条见 §1.1 表）。
- **证据 D（元层自增）**：M3-2 记录内同一 `2384` 出现 **10 处**（记录 9 + 索引条目 1；**复算**：`python3 -c "import re,pathlib;s=pathlib.Path('<记录>').read_text();print(len(re.findall('2384',s)))"` → 9，快照 `2026-10-14`），其中 **9 处落在 §8–§10 的「漂移叙述」**（§1–§7 = 0）；`37 例` 现网 **8 处**（记录 6 + 索引条目 2）。

**分类裁决**：

| 类别 | 裁决 | 依据 |
|:---|:---|:---|
| 阈值正当性基线（守卫下界） | **保留，改形态** | 直接影响门禁参数正确性；只需「下界 + 取值口径」，不必抄精确实测值 |
| 非空性 / 判别力判据 | **保留（单点）** | 是「守卫非空转」的证据本身；**具体允许面以 [AI 协作规范 §9](../../standards/ai-collaboration.md) 的例外面为唯一权威**（本节为**写录时点裁决**；2026-10-14 **收窄范围以 §9 为准**，本节不复述其组成） |
| 外部快照（run id / 下游 SHA / registry 版本） | **保留** | 归因必需，已有测量时点纪律 |
| 门禁读数复述（`verify` 总例数 / 分段计数 / `N 记录 / M 指针` / `N md / M 命令` / `N passed` / 受检文件数） | **降级为「命令 + 结果」** | 证据是命令而非数字；消费者为零；必然衰减 |
| 索引条目内的读数复述 | **移除**（只留结论 + 记录链接） | 与记录本体同源，是跨载体漂移的唯一来源 |

- **规范边界**：《AI 协作规范》只要求「结论 + **关键**实测值须落可提交位置」——现行做法**超出规范要求**，故收窄不违规范。

### 1.3 根因（四点）

1. **多载体 × 迭代次数**：一个数字平均落 8 ~ 10 处（§1.2 证据 D 的复算）；每个修复点都会后向失效此前写入的值 —— 9 处漂移中 **6 处**（§1.1 的 #2 / #3 / #4 / #5 / #6 / #7）由本批修复点后向失效造成。
2. **自指**：记录进入 integrity / structure / records / final-newline 受检面 → 写记录即改变其声明的数字。
3. **机检面覆盖不全**：`check-governance-counts` 仅覆盖 4 族且**只比 index ↔ 该条记录**；`N 例` 单族、脚本行数、章节标题、代码注释基线、历史记录衰减均不在面 —— 且注释与标题形态几无正则化空间。
4. **机检反向激励**：该守卫**以重复为前提**（无重复即无对账对象），从而把「索引复述读数」制度化。
