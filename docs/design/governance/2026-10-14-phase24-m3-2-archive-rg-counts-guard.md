## 2. 判别规则与受检面

| 环节 | 规则 |
|:---|:---|
| 条目识别 | 条目为列表项（`-` 加空格）且含 `**M<数字>` 编号锚点、含词边界形态的 `RG`（`RGETS` 之类词内命中不算） |
| 记录定位 | 条目行内指向 `design/governance/**` 的 Markdown 链接（**相对路径按条目文件所在目录解析**，故主窗口的 `../` 与深度归档的 `../../` 都成立） |
| 计数提取 | **仅全角括号内**：`（N blocker / N warning / N suggest）`（可缺项）或裸三元组 `（a / b / c）` |
| 轮次切分 | 按 `R<数字>` 切分；未标轮次的计数记 `FINAL`，与记录的**最后一轮**比对；同一轮次重复出现时保留首个非空取值 |
| 比对 | 逐 `(轮次, 字段)` 判定：仅当**两侧都有该字段**时计入可比对；有任一份候选记录读数一致即通过；全部候选都不一致才判 `rg-count-mismatch` |
| 下界 | `MIN_RECONCILED = 25`（本批实测 33）——可比对字段低于下界判 `scope-narrowed` |

- **记录侧章节抽取**：只取标题含 `Review Gate` 的章节，且**终止于同级或更高级标题**——子标题（如 `### x.x 结论`）不得截断父章节正文（首轮原型按「下一个任意标题」截断，导致 2 条条目「无候选记录」）。
- **有意不覆盖**：非条目段（`已知观察` / `遗留与后续候选` 等）；条目不写计数者（按「两处都有」口径跳过）；结论方向（`Pass` / `Reject`）本身不校验（方向由 Review Gate 台账承担）；**只处理顶层列表项**（缩进子条目不在面内；当前归档中此类行 0 例）。
- **残余风险（显式登记）**：多候选记录的「任一份一致即通过」意味着**单一记录侧**的漂移可能漏判——这是与「任一份矛盾即失败」之间取舍的结果（§3#3 已实测后者会误报），不是疏漏。

## 3. 首轮原型的问题源与消解（设计依据）

| # | 误报 / 漏报源 | 现象 | 消解 |
|:-:|:---|:---|:---|
| 1 | 计数允许括号外匹配 | 记录正文的轮次小节标签形如 `**R1 suggest**`，被读成 `suggest = 1`，覆盖真实计数 | 计数**只认全角括号内**表达式 |
| 2 | 父章节被子标题截断 | 记录把结论放在 `### x.x 结论` 下，抽取在子标题处结束 → 该条目「无候选记录」而静默跳过 | 章节终止条件改为「同级或更高级标题」 |
| 3 | 多记录链接按「任一矛盾即失败」 | 条目同时链接「初版记录 + 形态变更记录」时，另一份记录描述的是同一编号的**另一轮**审计 → 误报 | 改为**逐字段**判定「任一份一致即通过」 |
| 4 | 逐条目整体判定 | 同一候选记录上 `blocker` 一致、`suggest` 不一致时，因「已有字段一致」而整体放过 → 漏报 | 改为**逐字段**判定（与 #3 同一次修正） |

- #3 / #4 是同一处逻辑的两面：**判定粒度必须是字段，而不是条目或候选**。
