## 1. 结论摘要

- **立规则**：[AI 协作规范 §9](../../standards/ai-collaboration.md) 新增「**门禁读数不复述**」——门禁 / 守卫的命令输出计数**只写「命令 + 结果」**；仅三类可保留数值（阈值正当性 / 非空性 · 判别力判据 / 外部快照），且一律按「**写录时点快照**」表述、全部产物 staged 后复算；存量读数不回改。
- **索引约定**：[治理索引](./index.md) 新增「**摘要口径**」小节 —— 摘要只写结论 + 记录链接，不复述读数。
- **阈值口径化**：**13 个守卫文件 / 15 处**注释的「精确实测规模值」→ **口径 + 复算入口**（14 处规模读数 + 1 处观察性去量值），消除「注释里的数字随仓库增长而陈旧」这一类漂移源（该文件头正是 M3-2 被判 blocker 的位置）。
- **本记录自身即首个适用对象**：全文**不写任何门禁读数**（只写命令与 `exit 0`）—— 是该规则的首个可对照样例。

## 2. 规则落点（**不复述条文内容**）

> **本节刻意不复述条文内容**：规则的**单点定义**在 [AI 协作规范 §9](../../standards/ai-collaboration.md) 的「门禁读数不复述」条（含例外面与转述同值要求）。本节只登记**落点与执行口径**，避免「同一规则两处载体、改一处漏一处」——该形态在本条目 R1 / R2 连续两轮被判 blocker，故以**不复述**从结构上消除复发面（同方案 A 的思路：减少复述面优于事后对账）。

## 4. 边界

0. **本批原子性依据（粒度说明）**：**本批范围 = 13 个守卫注释口径化 + 规范条文 + 索引约定 + 本记录**；**规模一律以 `git diff --cached --name-only` / `--stat` 复算、此处不复述任何文件数或行数**（含本轮对依据记录的回改）。本批略超 [规划规范 §5](../../standards/planning.md) 的「10 文件」**建议**值 —— 属**同一交付面**（治理读数口径）的**机械同构**改动：13 个守卫**仅动注释**（`export const` 与判定逻辑逐字未变）+ 规范条文 + 索引约定 + 本记录；按 [AI 协作规范 §3.2.1](../../standards/ai-collaboration.md)「不得把一个大条目切成不满足最小验收标准的碎片」，拆分会产出无独立验收标准的碎片，故**不拆分**并以本节作为正当理由留痕。
1. **不改守卫的判定逻辑**：本批只改注释口径与规范条文，`SCOPE_FLOOR` / `MIN_*` 常量值**一律不动**（口径化不改变任何判定结果）。
2. **不纳入自然语言计数**：规范条文里仍可出现**规则叙述所需**的量级词（如「8 ~ 10 处」）—— 本批已尽量改为量级表述，但保留「凡写数须给命令」的既有条款兜底。
3. **不追溯存量记录**：历史记录与归档块中的读数按「写录时点快照」保留（点时记录不回改）。
4. **机检面**：本项**无机检守卫**（自然语言计数不可正则化），由 **Review Gate 必查**（「记录 / 索引是否复述门禁读数」）。
