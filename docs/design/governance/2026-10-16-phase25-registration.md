## 3. 非目标（本阶段）

- 不推送提交（M4-1 的推送以用户明确指令为前提）；不启用定时自动发布、不放开 `release.yml` publish、不进入 1.x。
- 不纳入 `Form` / `FormItem`（D5 维持候选、先出专项评估）与长尾组件（D6 按实测下游用量）。
- 不做破坏性 API 变更；不引入 Tailwind / UnoCSS；RTL 与二期语言集维持登记；不压缩历史快照类记录。
- 不引入高误报守卫（新增守卫须带负向对照与受检面下界）；`reka-ui` / `conventional-changelog` 维持条件触发。
