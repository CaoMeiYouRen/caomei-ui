## 3. 下游复验与修复（M6-4）

> 以下 run 时间均为 UTC（对应本地 2026-11-07 凌晨）。

- **失败 run**：[`42250122497`](https://github.com/CaoMeiYouRen/caomei-ui/actions/runs/42250122497)（发布链自动 dispatch，16:12:05Z 启动）在 `Override caomei-ui to target version` 报 `ERR_PNPM_NO_MATCHING_VERSION: No matching version found for caomei-ui@1.1.0`。根因 = **npm 传播延迟**（publish 成功 → registry 可解析约 3 分钟），dispatch 在 publish 后约 12 秒触发，下游 `pnpm add` 过早；非兼容性回归，也非 run #5 的 `minimumReleaseAge` 问题。
- **修复**：`release.yml` 的 `dispatch-downstream` job 新增 `Wait for npm availability`——`npm view caomei-ui@<v> version --prefer-online --registry=https://registry.npmjs.org` 以 **600s 总预算**轮询（间隔 20s、单次探测 ≤15s；`SECONDS` 计时，避免「次数 × 间隔」低估），可解析后才 dispatch；超时 fail-closed，并提示手动 `gh workflow run downstream-compat.yml -f caomei-ui-version=<v>`。job 超时由 10 分钟提到 15 分钟，保证超时分支可达。
- **复验 run**：[`42251067161`](https://github.com/CaoMeiYouRen/caomei-ui/actions/runs/42251067161)（显式入参 `1.1.0`）**success**，16:18:01Z → 16:19:54Z；`dependfix/dependfix @ ad592c928ec53a4c94fa3e64a079be6107d4b41e`；`Override` / `Assert minimumReleaseAge override` / `Typecheck downstream` / `Build downstream` 全部 success。
- **结论**：M6-4 的「一次真实发布触发下游检查并留痕」成立；正向方向（目标版本新于下游锁定版本）首次跑通，同时验证 run #5 的 `minimumReleaseAge` 修复。下次发布将自动走「等待 npm → dispatch」路径。
