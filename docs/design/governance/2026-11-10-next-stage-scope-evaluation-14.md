## 4. 规模与风险

1. **A4 ~ A6 合计 33 个组件页**：单条按交互族拆分后多为「补状态选择器 + 复用 token / E2E helper」，但跨组件文件数会超过 10 个的建议阈值；实施时按 A4 / A5 / A6 三条条目独立提交，必要时每条再按子族拆。
2. **基线**：`minimal` 必须保持零差异；新增动效只在 `data-motion="expressive"` 下生效，`reduce` 显式压平；每条完成后跑 `capture:styles` / `test:visual`。
3. **A7 后置理由**：DataTable 行重排 / 批量选择与固定表头的性能风险最高，且用户优先级最后；等 A4 ~ A6 的 E2E 装置复用成熟后再做。
4. **发布 1.3.0**：需先完成阶段全部条目 + Review Gate；发布前执行长期任务门槛复核（下一轮为第 33 轮）。
5. **本轮新增候选**：`check-stage-counts` 交叉校验与文档站 demo 过渡恢复已入 Backlog §1.6；若 D4 / D5 选择不纳入，仍作为候选保留（非阻塞）。
