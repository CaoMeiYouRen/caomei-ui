## 4. 风险与边界

1. **触摸 `change` 语义**：`nextTick` 延后仅影响「按下指针步进后 change 的读取时点」，键盘 / 失焦 / Enter 路径不变；若组件在同一 tick 内被卸载，延后回调仍可能补发一次 `change`（Vue 不阻止未挂载实例的 emit），监听方按既有 `change` 语义忽略即可，未新增监听。
2. **传递 major `@floating-ui/vue` 2.0.1**：2.11 起由 `1.1.11` 升到 `2.0.1` 并移除 `vue-demi`；本批以 `capture:styles` 0 差异 + 相关 E2E（含浮层与选择器族）231 passed 兜底，真实浏览器多视口下的定位差异仍属环境依赖面。
3. **`vfile-message` 4.0.4 漂移**：安装期 patch 解析，开发链（`vfile@6`）与 reka 解析面无关；未手工回改 lockfile，随下次依赖安装保持现状。
4. **测试装置依赖文档挂载**：`mountReady` 现固定 `attachTo: document.body` 并启用 `enableAutoUnmount`，后续新增用例沿用该 helper 即自动满足 2.11 的事件路径；另补一例 `pointerType: 'mouse'` 覆盖鼠标分支（`pointerdown` 即步进）并锁定 `change` 只发一次。
5. **例外清单只剩 Calendar `label-content-name-mismatch`**（axe 4.14 needsReview），本条目不触碰。
