> **本记录是 Phase 35 范围与验收口径的唯一载体**；`todo.md` 只做状态指针。

## 1. 阶段构成

- **编号推导**：取授权启动时已有最大编号 Phase 34 + 1 = **Phase 35**（[规划规范 §4](../../standards/planning.md)）。
- **3 条主线 / 10 条原子条目**：质量与无障碍收口 **5** / DataTable 进阶 **2** / 长尾组件 **3**（Rating 实现与导出 / locale 与台账 / 文档与测试）；构成对账 5 + 2 + 3 = 10。
- **不发布**：`latest` 维持 `1.3.0`；本阶段不触发 Release。
- **阶段级非目标**：DataTable 虚拟滚动（需新增运行时依赖）、i18n 二期 / RTL、Form 规则引擎、`useDialog`、Sidebar / ScrollPanel、破坏性 API、新增运行时依赖、自动发布、Storybook / Tailwind preset / 文档站多版本。
- **主线级非目标**：
  - M1：不扩展为全库 `inert` 改造；F18 只处理 Select 打开态的兄弟隔离；F17 只做实测与开关，不改提示默认行为（除非实测给出依据）。
  - M2：不做虚拟滚动、列固定扩展（既有 `frozen` 保持）、列拖拽排序；列宽只做受控与持久化契约，不引入新依赖。
  - M3：不做表单集成、自定义图标集、半星以外的复杂评分形态（按实现评估再定）。

## 3. 阶段规则

- **任务粒度**：单条 ≤ 10 文件 / 800 行；超出时按 §5 拆分（同批更新三处计数）。
- **质量门**：每条目 `lint` / `typecheck` / 定向测试 / 必要 E2E / Review Gate；阶段末 `pnpm verify`。
- **Review Gate**：每条目至少一轮 `@code-reviewer`；未 `Pass` 不得提交。
- **文档**：组件能力变化同步中英组件页、`design-spec` / `components.md` / 画廊与侧栏登记；不虚构未实现能力。
- **发布**：本阶段不发布；`release.yml` 与发布触发模型不改。
- **编号**：Phase 35 于 2026-11-15 登记；条目编号只在阶段内使用，不回写历史。
