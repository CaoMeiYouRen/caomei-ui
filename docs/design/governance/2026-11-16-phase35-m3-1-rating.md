## 2. 决策

1. **按 Reka 的官方分数步进模型渲染**：每个 `RatingItem` 展开为若干 `RatingItemIndicator`（`step=0.5` 时每星两个），指示器宽度 / 透明度 / 层级直接消费 primitive 的 `--reka-rating-item-step-width` / `-opacity` / `-z-index`，`overflow: hidden` 完成半星裁切——不自造指针坐标换算，键盘与点击都走 primitive 的 RadioGroup 语义。
   **着色只取「不超过当前分值的最右一格」**（`paintedSteps`）：primitive 对 `≤ 当前值` 的所有 step 都置 `data-state="active"`，若按 active 着色会把半星叠成整星；悬停预览由组件自己按 step 的 `mouseenter` 记录（离开评分区域清空）。
2. **只读 = `disabled` + `aria-readonly`**：primitive 无只读态；`readonly` 落到 `disabled`（不可聚焦、不可改值），并输出 `aria-readonly="true"` 与 `data-readonly` 供样式区分。`disabled` 另加降透明度与 `--disabled` 类。
3. **文案不进组件**：每个 step 的 `aria-label` 只用数值（`3.5`），评分区域名取 `label`；面向用户的分值文案（如「3.5 分 / 共 5 分」）留给使用方与语言层，避免在组件里硬编码。
4. **图标走语义名**：新增 `star` 到内部图标表，下游可用 `provideIconOverrides()` 替换，符合既有图标体系约定。
5. **样式全用 CSS variables**：`--caomei-rating-icon-size`（档位）/ `--caomei-rating-gap` / `--caomei-rating-empty-color` / `--caomei-rating-fill-color`，暗色与主题预设无需额外分支。
