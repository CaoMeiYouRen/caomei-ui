## 1. 阶段构成

- **编号推导**：取授权启动时已有最大编号 Phase 40 + 1 = **Phase 41**（[规划规范 §4](../../standards/planning.md)）。
- **5 条主线 / 15 条原子条目**：表单校验 **4** / 日期形态 **2** / 治理与可达性 **2** / 移动组件 **3** / 移动文档 **4**；构成对账 4 + 2 + 2 + 3 + 4 = 15。
- **登记时点拆分**：第二十六轮评估的 A 为 **4 主线 / 14 条（M4 6 条）**（提名期值）；登记时把 8 个高流量页面移动说明按「8 页 × 中英 = 16 文件」拆为 **M5-2 / M5-3**（各 4 页），壳层示例为 **M5-4**；原 M4-4 顺延为 **M5-1**（移动端就绪矩阵）；同时把移动端按「组件 / 文档」拆为 **M4 / M5** 两条主线，使单主线不超过 5 条。故登记值为 **5 主线 / 15 条**，评估草案的 4 主线 / 14 条为提名期时点值。
- **主线性质**：M1 / M2 / M4 为功能主线；M3 为治理主线；M5 为文档主线；5 条落在[规划规范 §6](../../standards/planning.md) 的 3–6 条区间，15 条在建议区间 10–15 内（未超硬上限 20）。
- **D0 ③ 与 D0' ① 的覆盖关系**：D0 ③ 的「P2 两件」已被 D0' ①（A 移动优先，P2 延后）覆盖；Statistic / Countdown 留在 Backlog §1.11。两轮条目数同为 15，但构成不同（D0 ③ 草案为 5 主线含 P2；登记为 5 主线含移动）。
- **范围来源**：表单校验见第二十五轮 C1；日期形态见 C2；治理与可达性见 C8 / C18；移动端见第二十六轮 C1 / C2 / C7 ~ C10。
- **用户已裁定不纳入**：P2 组件（Statistic / Countdown）延后（D0' ①）；发布收口移出（D3 ③，`latest` 维持 `1.4.0`）；国际化二期 7 语、Tree / TreeSelect、RTL、DataTable 虚拟滚动、宽屏视觉基线 / `xl` 断点、单 Demo 抽屉、依赖与工具链升级维持候选。
- **阶段级非目标**：不做通用 Picker 实现（只保留 Backlog 候选）；不做手势件（PullRefresh / InfiniteScroll / SwipeCell / IndexBar / FloatingBubble / 图片捏合预览 / Signature）；不做 `NumberKeyboard` / `NoticeBar` / `List` / `Grid`；不新增运行时依赖；不做破坏性 API；不自动发布；不进入 2.0。
- **主线级非目标**：
  - M1：不做 Element Plus 式 `rules` DSL；不做异步校验请求管理；不替换 13 个字段的既有契约；不改 `FormItem` 现有插槽作用域。
  - M2：不做 `selectionMode="multiple"`；不做月 / 年与 `showTime` 的组合；不改 `single` / `range` 语义；不做 RTL 日期面板。
  - M3：不重写既有归档块；不追溯 6 项字段的历史块；不改 400 行阈值与索引正序。
  - M4：不接 vue-router；不改 `Tabbar` / `ActionSheet` / `Cell` 的既有 API；不做手势件。
  - M5：不做全量 41 个未提及移动的组件页说明；不改 `mobile.md` 的既有断点语义。

## 3. 阶段规则

- **任务粒度**：单条 ≤ 10 文件 / 800 行；移动文档条目（原 M4-4 ~ M4-6）的拆分与顺延见 §1。计数回扫按[规划规范 §3.9](../../standards/planning.md) 覆盖 `todo.md` / `roadmap.md` / 本记录 / 索引摘要 / `.session`。
- **执行顺序建议**：先做 M3（治理与可达性，两个小批次），再做 M1 / M2，最后 M4 / M5（移动组件与文档无强依赖，但文档批次宜在前三者稳定后收口）。
- **NavBar 例外管理**：M4-1 / M4-2 是用户 D1' ① 明确授权的例外项；文档与提交正文须标注「第 1 条不成立、第 2 条存疑（三条未全部满足）」，不得写成「满足三条标准」。若后续用户撤回例外，M4-1 / M4-2 移出并重算为 13 条。
- **质量门**：每条目 `lint` / `typecheck` / 定向测试 / 必要 E2E / Review Gate；阶段末 `pnpm verify`。
- **状态词**：条目表沿用 `待执行 / 已交付`；进度表用 `未开始` / `进行中` / `已闭环` / `已阻塞`。映射：未开始 / 进行中 → 待执行，已闭环 → 已交付；已阻塞 → 待执行（阶段收口前须转为已交付或移出）。
- **Review Gate**：每条目至少一轮 `@code-reviewer`；未 `Pass` 不得提交。
- **文档**：组件能力变化同步中英组件页与设计登记；不虚构未实现能力；移动文档标注「无下游代码验证」。
- **发布**：用户 D3 ③ 已裁定**不发布**；`latest` 维持 `1.4.0`，未发布变更（`DatePicker` 宽度 / `TimePicker` 默认秒 / `labelAttrs`）留在 master，下一次发布统一收口。
- **依赖**：不新增运行时依赖。
- **issue #71**：由 M3-1 收口并关闭；关闭前不得在 `todo.md` / `roadmap.md` 复写其细节。
