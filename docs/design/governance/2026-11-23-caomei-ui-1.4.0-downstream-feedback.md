## 3. 反馈事实

### 3.1 caomei-auth

- `CaomeiButton` 根节点的父级 scoped id 被 `CaomeiPassthrough` 截断，主题切换、发送验证码、头像上传、复制、会话 / 2FA、SSO、授权同意等按钮的 scoped 样式失效；11 个文件改用祖先 + `:deep()`。
- 社交按钮的 `display` / `border` 被库样式覆盖；库规则与项目规则同为双类特异性且库后加载，最终以 `!important` 恢复卡片高度与边框色。
- ja / ko 长语言登录标签组被 1.4.0 的按钮内容 `nowrap` 撑出卡片，登录页局部恢复 `white-space: normal`。
- Admin 表头 +2px，归因到 1.4.0 的单元格 `CaomeiTooltipText` 包装；重采 30 张视觉基线。
- 项目治理记录已把根节点问题定性为「库级兼容性缺口，不是本项目独有」。

### 3.2 momei

- 全仓扫描出 35 个 class 选择器 / 25 个文件受根节点 fragment 影响，统一改 `:deep()` 锚定祖先 scope 属性；修复后桌面端本应隐藏的移动按钮恢复隐藏。
- 表头行高由 32.59px 增至 35.69px，表格与空态整体下推 3px；下游以未分层 `.caomei-tooltip-text { vertical-align: top }` 抵消。
- 按钮内容改为单行截断契约后，主题画廊卡片页脚按钮的自然宽度成为列最小内容宽，卡片宽度 188 → 200px；按上游契约接受并重采明暗两条基线。
- 记录明确把这 3 项列为「本仓必须修复的上游形态回归」。

### 3.3 dependfix

- `1.2.0` 的 DatePicker `update:modelValue` 放宽为 `Date | [Date, Date] | null`，下游出现 TS2769；在 PR 内补类型收窄后合并。
- `1.0.0-rc.1` 把表头全选从「全部行」收窄为「当前页」；下游新增选择栏与 `selectAllScope` 适配。
- `1.4.0` 起 Select / MultiSelect / AutoComplete 展开态给面板外兄弟节点补 `inert` + `aria-hidden`；面板外第一下点击只关闭面板，被点元素收不到该次点击，e2e 收合手势改为点字段内触发器。
- 表头 +3px、分页器每页条数选择器 6rem → 5rem / 32px、Select 面板内部滚动、按钮 `nowrap` 均按实测接受并归因。
- Dependabot 未及时升级是「默认 3 天冷却 + 周更」叠加，与组件库无关；首轮 e2e 失败是本地 `data/e2e.sqlite` 累积所致，清理后全绿。

## 5. 处置

- **P0 → Phase 42 M6（2 条）**：M6-1 修复 DataTable 表头行高并加守卫；M6-2 补 1.4.0 消费方可见变化升级注意。Phase 42 构成由原登记 **5 条主线 / 15 条原子条目** 追加为 **6 条主线 / 17 条原子条目**（3 + 2 + 3 + 5 + 2 + 2 = 17）。
- **其余 → Backlog（6 项）**：§1.6 四项（Button 单元素根、Button 换行开关、CSS `@layer`、升级影响面评估自动化）、§1.1 一项（`inert` 首击）、§1.8 一项（三家下游 1.4.0 适配回收）。候选池由 36 回流为 42（36 + 6 = 42）。
- **后续版本升级规则**：写入[发布指南](../../guide/release.md) §10.1——每次发布须逐条分级 `BREAKING` / 消费方可见非 `BREAKING` / 仅内部；消费方可见变化必须写升级注意；涉及 DOM / 默认样式 / 交互时序时须跑下游视觉或关键流回归；下游反馈须回流 Backlog 或治理记录。

## 6. 下游适配与复评

- **caomei-auth**：`:deep()` 为正确规避；`!important` 与登录页 `white-space: normal` 是应急，待上游 Button 根节点 / 换行开关修复后复核删除。社交按钮覆盖建议补计算样式断言。
