# Components

caomei-ui provides desktop- and mobile-friendly components built on [Reka UI](https://reka-ui.com/). Every component ships minimal default styles and exposes CSS variables for full overrides.

## Translated component pages

Component pages are translated incrementally, in order. Pages available in English so far:

- [Button](/en-US/components/button)
- [Input](/en-US/components/input)
- [Select](/en-US/components/select)
- [Checkbox](/en-US/components/checkbox)
- [Dialog](/en-US/components/dialog)
- [DataTable](/en-US/components/data-table)
- [Toast](/en-US/components/toast)
- [Card](/en-US/components/card)

Until a page is translated, refer to the Chinese documentation.
