# Component Gallery

A curated set of representative components, rendered **live** and grouped the same way as the [components overview](/en-US/components/) and the sidebar. Every card is interactive — follow the component name to its documentation page.

> The gallery is a curated subset of the [components overview](/en-US/components/) and does not replace each component's full documentation. The registry and its reconciliation rules are documented in the Chinese [documentation site design](/design/documentation-site) (§16).
