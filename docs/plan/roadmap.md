# caomei-ui 项目路线图

本文档展示 caomei-ui 的发展路线与阶段规划。任务执行状态见 [待办事项](./todo.md)，长期候选见 [Backlog](./backlog.md)，周期性治理见 [长期任务](./recurring.md)，已完成阶段见 [待办归档](./todo-archive.md)。

> 定位：caomei-ui 是一个基于 Vue 3 + Reka UI 的自建组件库，用于替代多个下游项目中的 PrimeVue，规避 PrimeUI 商业许可风险。

## 1. 现状与背景

- 技术栈：Vite + Vue 3 + TypeScript，单仓库单包；组件库构建用 tsdown。
- 当前状态：`latest` = 0.7.0；**Phase 26 为当前进行中阶段**（1.0 发布前收尾，2026-10-22 登记）。**2026-10-26 UI 自检发现新的 P0 / P1 项后，1.0 发布延后并受门禁 G0 ~ G4 约束**；Phase 26 执行期追加 M5 插队批次 4 条（原登记 4 条主线 / 13 条原子条目 → 5 条主线 / 17 条原子条目），**M5 已全部交付、G0 于 2026-10-28 通过；G1 同日裁定「修复」并完成 G1-F（tone 文本 / 控件边界 / 全预设矩阵）；同日按用户指令完成 S1 依赖安全告警清理（15 项开发作用域告警在解析层清零）与 S2 Code Scanning 清理（5 项），**G2 质量门同日通过**；2026-10-29 追加 S3 安全告警门禁 CI 接入（G2 通过后、rc 前生效）；G3 前置检查完成，当前因 npm 凭据失效（401 / 默认 registry 为镜像）阻塞**。门禁与时间盒见[执行期追加与 1.0 发布门禁](../design/governance/2026-10-26-phase26-ui-gate-planning.md) §4。Phase 24 遗留两条已于 2026-10-22 回填（视觉基线 run success / CI 镜像未命中），待独立归档批次，见[待办事项](./todo.md)。
- 组件与已落地能力清单以[组件设计](../design/components.md) 与仓库根 `README` 为单一事实源；版本变更史见仓库根 `CHANGELOG`。
- 目标下游：afdian-linker、caomei-auth、momei、rss-impact-next、dependfix/apps/platform。
