## 1.4.0 里程碑

本版本收敛 `1.3.0` 之后积累的 Phase 36 ~ 41（新增组件、DataTable 能力面、内建提示、移动端壳层与表单编排）。默认路径仍保持逐值等价，但本版有**若干消费方可见的形态变化**：`CaomeiButton` 的根节点形态、按钮内容单行截断、`DataTable` 文本包装、浮层展开态的 `inert` 隔离以及 Paginator / Select 的几何。三家下游升级时均命中其中至少一项，逐项研判（含各自原始记录与测量口径）见 [1.4.0 下游升级反馈研判](../design/governance/2026-11-23-caomei-ui-1.4.0-downstream-feedback.md)；下表计数引自该记录 §2 / §3，下游测量时点为 2026-11-22（caomei-auth）与 2026-11-23（momei / dependfix）。

## 新增能力

- **新组件**：`BackTop` / `Cell` · `CellGroup` / `Tabbar` · `TabbarItem` / `ActionSheet` / `Empty` / `Cascader` / `Descriptions` / `Rating` / `Result` / `TimePicker` / `Timeline` / `Transfer` / `InputOtp` / `Popconfirm`。
  > **事实修正（2026-11-24）**：`NavBar` 属 Phase 41，计划随 `1.5.0` 发布，不在本版（初版此处误列，已按用户裁定修正）。
- **DataTable**：列宽拖拽、受控列可见性与列顺序、受控列宽与持久化契约、固定表头与限高滚动、`selectAllScope` 全选作用域、逐格提示开关（`cellTooltips`）。
- **内建提示**：`CaomeiTooltipText` 溢出提示接入 DataTable 表头 / 单元格、Button、Dialog 关闭、Paginator 翻页、SplitButton、Toolbar 等位置。
- **移动端**：固定定位件接入安全区 token 与 `dvh` 回退（命中区原语 `--caomei-hit-target-min` 及其 P0 / P1 / P2 批次沿用 `1.3.0`）。
- **国际化**：数字与文件体积跟随注入语言格式化；日期组件 locale 跟随。

## 消费方可见变化

### Button 根节点变为多根（Passthrough）

- **变化**：两条分支都不再渲染单一 `<button>` 根——未启用提示时走 `CaomeiPassthrough`，启用时走 `CaomeiTooltip`（其内部再按 Provider 选 `Passthrough` / Provider），插槽内容在 vnode 层是 Fragment；`1.3.0` 的根是直接 `<button>`。
- **影响**：下游对「父级 scoped 选择器 + 子组件根元素」的写法失效——父级的 `data-v-*` 落不到按钮元素上，`.parent-class .caomei-button` 形式的 scoped 样式不再命中。
- **复现**（caomei-auth 实测）：给父级写 `scoped` 样式 `.toolbar .caomei-button { ... }` 并渲染 `<CaomeiButton>`；`1.3.0` 生效、`1.4.0` 失效。该仓 11 个文件改用「祖先类 + `:deep(.caomei-button)`」后恢复。
- **适配**：

  ```css
  /* 1.3.0：父级 scoped 直接命中 */
  .toolbar .caomei-button { --caomei-button-bg: #fff; }

  /* 1.4.0：改用 :deep()，或把类挂到组件自身 */
  .toolbar :deep(.caomei-button) { --caomei-button-bg: #fff; }
  ```

### Button 内容改为单行截断（`nowrap`）

- **变化**：`.caomei-button__content` 由 `inline-flex` 改为 `display: block` + `white-space: nowrap` + `text-overflow: ellipsis`，为截断与溢出提示服务。
- **影响**：长文案不再换行，按钮按内容自然宽度撑开；ja / ko 等长语言在窄容器内可能溢出。
- **复现**（caomei-auth 实测）：登录页短横排按钮组放入 `ja-JP` / `ko-KR` 文案，`1.4.0` 下标签单行超出卡片；该页局部恢复 `white-space: normal` 后正常。
- **适配**：给按钮容器留足宽度，或在业务侧局部恢复换行（`.caomei-button__content { white-space: normal }`，配合容器 `min-width`）；当前无内建换行开关，候选见 [Backlog](../plan/backlog.md)。

### DataTable 表头 / 单元格文本包装（行高）

- **变化**：表头与默认单元格文本包进 `CaomeiTooltipText`（可测量的 `inline-block`）。列宽受限（带绝对列宽）时启用单行省略，截断后悬停显示全文。
- **影响**：截断配方（`overflow: hidden`）会让 `inline-block` 的基线改为底边，行盒多出降部空间：本仓夹具实测表头 `34.5 → 37.5px`、单元格 `35 → 38px`；momei 实测表头 `32.59 → 35.69px`。表格与空态因此整体下推约 3px。
- **复现**（momei 实测）：Admin 列表页升级后表头 +2~3px、30 张视觉基线重采；dependfix 同步观测到表头 +3px。
- **适配**：库内修复已合入主干，**随 `1.5.0` 发布**（写录时点 2026-11-24，`1.5.0` 尚未发布）：表头与默认单元格的文本盒统一 `vertical-align: top`，含 `cellTooltips=false` 的降级盒。停留在 `1.4.x` 期间可整段复制下面的抵消写法（与库内规则同形）；基线下推属预期，抵消后需重采。

  ```css
  .caomei-data-table__th .caomei-tooltip-text,
  .caomei-data-table__td .caomei-tooltip-text,
  .caomei-data-table__td .caomei-data-table__cell-box {
      vertical-align: top;
  }
  ```

### 浮层展开态的 `inert` 隔离

- **变化**：Select / MultiSelect / AutoComplete / DropdownMenu / Popover / DatePicker / ColorPicker 展开时，面板外兄弟节点补 `inert` + `aria-hidden`；Dialog / Drawer 同源。
- **影响**：面板外第一下点击只用于关闭面板，被点元素收不到该次点击；依赖「点外部即触发动作」的手势 / 自动化需改。
- **复现**（dependfix 实测）：e2e 收合手势原本点击面板外按钮，升级后首次点击被吞；改为点字段内触发器后通过。
- **适配**：自动化点「面板内触发器」或先 `Esc` 关闭；业务交互避免把「关闭 + 立即动作」压在面板外同一次点击上。当前为有意设计，是否「不吞首击」在 [Backlog](../plan/backlog.md) 评估。

### Paginator / Select 相关变化

- **自 `1.3.0` 起生效（从 `1.2.0` 及更早升级时可见）**：Paginator 每页条数选择器宽度 `6rem → 5rem`、高 32px，自定义用 `--caomei-paginator-rows-width` / `--caomei-paginator-control-size`；Select / MultiSelect / AutoComplete 面板改为高度上限 `min(15rem, 可用高)` + 内部滚动 + `overscroll-behavior: contain`（覆盖 `.caomei-select__viewport` 的 `max-height` 可放宽）。dependfix 为 `1.2.0 → 1.4.0` 跨版本升级，观测到的是这两项累积结果。
- **`1.4.0` 实际改动**：Paginator 翻页图标按钮接入内建提示、每页条数选项与页码数字随注入语言格式化；Select 新增 `allowEmptyValue`（放行空串选项值），几何不变。
- **复现**：从 `1.2.0` 直接升到 `1.4.0` 时按上述 `1.3.0` 口径核对；从 `1.3.0` 升级只需关注提示与数字格式化。

## 升级注意

- **Button 根节点不是单一元素**：父级 `scoped` 选择器需经 `:deep()`，或把样式挂在组件自身的 `class` 上。未启用提示时同样如此（Passthrough 分支）。
- **Button 内容单行截断**：长文案不再换行；ja / ko 等长语言在窄容器内会溢出，需要换行时先在容器层约束。
- **DataTable 行高**：`1.4.0` 期间表头与默认单元格行高较 `1.3.0` 增加 2~4px（随字体度量）；库内修复随 `1.5.0` 发布。停留 `1.4.x` 时用 `vertical-align: top` 抵消，恢复后需重采视觉基线。
- **浮层 `inert` 首击**：面板外第一下点击只关闭面板；自动化改点面板内触发器。
- **Paginator / Select 几何**：分页器每页条数选择器变窄变矮、Select 长列表改为面板内滚动；依赖像素位置的断言需更新。
- **`selectAllScope`**：表头全选默认仍为「当前页」；需要整表语义时显式传 `"all"`。
- **DatePicker 值类型（自 `1.2.0` 起）**：范围选择把 `v-model` 类型扩为 `Date | [Date, Date] | null`，运行期 prop 无法静态窄化，可能导致下游 `typecheck` 失败；按 `selectionMode` 收窄绑定类型即可（见 [版本策略](../guide/version-policy.md)）。
