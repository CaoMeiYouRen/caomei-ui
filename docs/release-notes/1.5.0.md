## 1.5.0 里程碑

本版本收敛 `1.4.0` 之后积累的 Phase 41 ~ 42（表单最小校验层、日期月 / 年粒度、移动端壳层与文档、P2 展示组件、宽屏视觉基线与下游兼容修复）。新增能力均为**增量**：除下列各项外，页面默认渲染与 `1.4.0` 等价。本版包含两项下游可见修复（`DataTable` 表头 / 单元格行高回到 `1.3.0`、可访问名收口 `labelAttrs`）、两项展示默认值调整（`TimePicker` 默认展示秒与内容宽度、`DatePicker` 触发器默认宽度）、`TimePicker` 段位输入的 DOM / 输入类型重做，以及 `CaomeiForm` 的提交语义。

## 新增能力

- **`CaomeiForm` 最小校验层**：`Form` 承接 `submit` 编排与内建校验、`FormItem` 透传 `validate` / `validation-mode`；校验失败时**不 emit `submit`**，并聚焦文档顺序首个无效字段；`errors` 支持服务端回填，字段值变化即让位。无 rules DSL，既有 `invalid` / `error` 通道继续可用。
- **`DatePicker` `month` / `year` 粒度**：`selectionMode` 扩为 `single` / `range` / `month` / `year`，值仍为 `Date` 并按粒度归一化（月 → 当月 1 日、年 → 1 月 1 日）；`showTime` 与月 / 年组合会告警并忽略。
- **`Statistic`**：大号数值展示，精度 / 千分位 / 前后缀 / 加载态；空值与非法输入降级为占位，不隐式按 `0`。
- **`Countdown`**：目标时间倒计时，`DD` / `HH` / `mm` / `ss` / `SSS` 模板；到点触发 `finish` 并停表冻结，回拨不恢复。
- **`NavBar`**：路由级页头（返回 / 标题 / 尾部操作、可选吸顶与安全区），不接 vue-router，**首次随本版发布**。**例外项**：不满足[例外项声明](https://github.com/CaoMeiYouRen/caomei-ui/blob/master/docs/components/nav-bar.md)所述三条准入标准第 1 条未满足、第 2 条存疑，按用户例外立项，不作为「三条已满足」的先例。
- **移动端**：移动就绪矩阵、高流量页面说明、壳层示例与「模拟（非真机）」验收记录。
- **可访问名收口（`labelAttrs`）**：`TimePicker` 滚轮列与 `Cascader` / `Timeline` / `Transfer` 的模板级 `aria-label` 改走统一转发通道；空标签不再渲染空 `aria-label`（见升级注意）。
- **质量装置**：宽屏视觉基线（`DataTable` / `Form` 在 1536 / 1920 的亮暗基线）与阶段收口执行 `pnpm typecheck:docs`。

## 消费方可见变化

### `DataTable` 表头与单元格行高恢复（修复）

- **变化**：`1.4.0` 把表头与默认单元格文本包进 `CaomeiTooltipText`，截断列的行盒多出降部空间（下游实测表头 `32.59 → 35.69px`）。本版把表格内文本盒统一 `vertical-align: top`（含 `cellTooltips=false` 的降级盒），行高回到 `1.3.0`。
- **影响**：`1.4.0` 期间重采过表格相关视觉基线的下游需要**再重采一次**；未重采者会看到约 2~4px 的基线差异。
- **复现**：对照 `1.3.0` 与 `1.4.0` 的表头 `getBoundingClientRect().height`；本仓守卫见 `test/e2e/data-table-header-height.e2e.ts`。

### `CaomeiForm` 的提交语义

- **变化**：表单声明了 `validate` 时，提交会先校验；**校验失败不 emit `submit`**，也不抛出异常——失败信息通过字段错误文案与 `role="alert"` 呈现，焦点移到首个无效字段。
- **影响**：把 `@submit` 当作「点击即提交」的下游需注意：未通过校验时不会收到事件；需要「无论校验如何都执行」的逻辑放到 `@submit` 之外（如按钮自身的事件）。
- **复现**：给一个必填 `FormItem` 传返回文案的 `validate`，提交后观察 `submit` 未触发、字段显示错误。

### `TimePicker` 默认展示秒与内容宽度

- **变化**：`showSeconds` 默认值 `false → true`（字段默认展示时 / 分 / 秒）；字段默认宽度从选择器家族的 `20rem` 改为时间内容档位；`pad` 为新增开关，默认开启（补 0）。
- **影响**：依赖「只展示时 / 分」或固定 `20rem` 宽度的页面会看到新形态。
- **适配**：显式传 `:show-seconds="false"` 回到旧行为；宽度用 `--caomei-time-picker-max-width` 覆盖；`pad` 不需要补 0 时传 `:pad="false"`。

### `TimePicker` 段位输入改为文本输入

- **变化**：内联段位由 `type="number"` 改为 `type="text"` + `inputmode="numeric"`，移除原生 `min` / `max` / `step`；段位外层新增 `<span class="caomei-time-picker__segments">`，段位补 `role="spinbutton"` 与 `aria-valuemin` / `aria-valuemax` / `aria-valuenow` / `aria-valuetext`（空值时不输出 `role` 与四个 `aria-value*`）。12 小时制 AM/PM 选择器类名由 `__day-period` 改为 `__period`；`mode="wheel"` 的字段外壳由按钮改为容器 + 内嵌 `__trigger`。
- **影响**：`input[type="number"]` 选择器不再命中；原生数字步进按钮消失；`valueAsNumber` 不可用；外层 `<form>` 的 `min` / `max` / `step` 原生约束校验不再生效。
- **适配**：选择器改用 `input.caomei-time-picker__segment`（`mode="wheel"` 的只读展示同样是该 class 的 `<span>`）；AM/PM 选择器改用 `.__period`；取值范围仍由组件夹取，步进语义只作用于上下方向键（`:step`）。

### `DatePicker` 触发器默认宽度

- **变化**：触发器默认宽度从选择器家族的 `20rem` 改为日期内容档位（日期 `12rem` / 含时间 `15rem` / 区间 `18rem` / 月·年 `13rem`）。
- **影响**：与同列表单并排时宽度不再自动对齐；依赖 `20rem` 的布局需复核。
- **适配**：覆盖 `--caomei-date-picker-max-width`（`100%` 或 `none` 可恢复随容器 / 自适应）。

### `DatePicker` 月 / 年粒度

- **变化**：`selectionMode="month"` / `"year"` 下 `v-model` 仍为 `Date`，但值被归一化到**本地时区**的当月 1 日 `00:00` / 1 月 1 日 `00:00`；月 / 年粒度**不支持** `showTime`，时间层被忽略并给出开发期告警。
- **影响**：只关心「哪个月 / 哪一年」的页面可直接用；若下游自行做了日期归一，需确认不重复截断。

## 下游迁移最小示例

内建校验与 `errors` 回填的最小写法（不改变既有受控通道）：

```vue
<script setup lang="ts">
import { ref } from 'vue'

const name = ref('')
const errors = ref<Record<string, string>>({})

function validateName(value: unknown): string | undefined {
    return typeof value === 'string' && value.trim() ? undefined : '请输入名称'
}

function onSubmit(): void {
    // 仅在全部字段通过校验后触发
}
</script>

<template>
    <CaomeiForm :errors="errors" @submit="onSubmit">
        <CaomeiFormItem label="名称" name="name" :model-value="name" :validate="validateName">
            <!-- 默认插槽作用域是 id / 可访问名 / invalid 的唯一出口：不透传会丢标签关联与错误态 -->
            <template #default="{ id, name: fieldName, invalid, ...aria }">
                <CaomeiInput
                    :id="id"
                    :name="fieldName"
                    v-model="name"
                    v-bind="aria"
                    :invalid="invalid"
                />
            </template>
        </CaomeiFormItem>
        <CaomeiButton type="submit">提交</CaomeiButton>
    </CaomeiForm>
</template>
```

- 服务端错误：`errors.value = { name: '该名称已被占用' }`（整体替换对象）；字段值变化后该字段错误自动让位。
- 返回值约定：返回文案即失败、返回空值即通过；数组只渲染首个非空文案；**不支持布尔**（类型层面不接受，运行时 `false` 视为通过、`true` 会被当作错误文案渲染）。

## 升级注意

- **`TimePicker` 默认展示秒与宽度**：`showSeconds` 默认改为 `true`、字段默认宽度改为时间内容档位；需要旧行为时传 `:show-seconds="false"`，宽度用 `--caomei-time-picker-max-width`。
- **`TimePicker` 段位输入改为文本输入**：`input[type="number"]` 不再命中、原生步进按钮消失、`valueAsNumber` 不可用、原生 `min` / `max` / `step` 校验失效；选择器改用 `input.caomei-time-picker__segment`、AM/PM 改用 `.__period`，范围仍由组件夹取。
- **`DatePicker` 触发器默认宽度**：改为日期内容档位（12 / 13 / 15 / 18rem；月·年为本版新增模式，仅 12 / 15 / 18rem 涉及升级），与同列表单并排时不再自动对齐；覆盖 `--caomei-date-picker-max-width` 恢复。
- **可访问名收口（`labelAttrs`）**：`TimePicker` 滚轮列与 `Cascader` / `Timeline` / `Transfer` 的模板级 `aria-label` 改走统一转发通道，**空 `label` 不再渲染空 `aria-label`**；无迁移动作，依赖「恒有 `aria-label` 属性」的测试需按空值分支调整。
- **`DataTable` 行高回到 1.3.0**：`1.4.0` 期间重采的表格视觉基线需再重采；停留在 `1.4.x` 的抵消写法（`vertical-align: top` 三选择器组）在本版起可由库内规则替代，移除后请复核基线。
- **`Form` 提交语义**：声明 `validate` 时校验失败不 emit `submit`、不抛异常；勿把「提交后必然执行」的逻辑只挂在 `@submit` 上。
- **`DatePicker` 新增粒度**：`selectionMode` 取值增加，若下游用联合类型穷举 `selectionMode`，需补 `month` / `year` 分支。
- **`NavBar` 为例外项**：不满足组件准入标准第 1 条未满足、第 2 条存疑，不构成「三条标准已满足」的先例；使用前请确认页头职责边界。
- **无破坏性变更**：本版无 `BREAKING CHANGE`；`1.4.0` 的 Button 根节点形态、按钮内容 `nowrap`、浮层 `inert` 首击等变化见 [1.4.0 发布说明](https://github.com/CaoMeiYouRen/caomei-ui/blob/master/docs/release-notes/1.4.0.md)。

## 已知限制

- 移动端验收为**浏览器设备视口模拟（非真机）**：iOS 地址栏动态收缩、触摸惯性滚动、系统 OTP 填充与安全区让位仍未在真机验证，详见[移动端与响应式](https://github.com/CaoMeiYouRen/caomei-ui/blob/master/docs/guide/mobile.md)的「真机执行记录」。
- `Statistic` / `Countdown` 无内置文案，`label` / `finishText` 由使用方提供；两组件不新增 locale 命名空间。
- 宽屏视觉基线覆盖 `DataTable` 与 `Form` 两档（1536 / 1920），`xl` 断点与宽屏布局规则仍为 [Backlog](https://github.com/CaoMeiYouRen/caomei-ui/blob/master/docs/plan/backlog.md) 候选。
